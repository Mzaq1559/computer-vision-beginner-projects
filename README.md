# Computer Vision Beginner Projects

Small Python + OpenCV projects for learning Computer Vision fundamentals.

## Projects

- 01 - Image Basics
- 02 - Color Detection
- 03 - Face Detection
- 04 - Motion Detection

Start with `01-image-basics` and progress through the folders.

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
